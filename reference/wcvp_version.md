# Functions to help check the WCVP data is okay and up to date. View the version of WCVP available.

Functions to help check the WCVP data is okay and up to date. View the
version of WCVP available.

## Usage

``` r
wcvp_version(long = TRUE)
```

## Arguments

- long:

  Whether to return the version date with version number.

## Examples

``` r
wcvp_version()
#> Version 16 (04 Jun 2026)
```
